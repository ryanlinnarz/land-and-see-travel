# Land & See Travel — Version 1

This is a static website designed for free hosting on Cloudflare Pages.

## Files

- `index.html` — homepage
- `styles.css` — responsive styling
- `script.js` — small navigation/year script
- `assets/` — your supplied Land & See logo and travel photos

## Free deployment plan

Recommended stack:

1. Create a free GitHub account/repository.
2. Upload the contents of this folder to the repository.
3. Create a free Cloudflare account.
4. In Cloudflare Pages, connect the GitHub repository.
5. For a plain static site, use:
   - Build command: none / leave blank
   - Build output directory: `/` or the repository root, depending on the Cloudflare Pages setup shown to you.
6. Cloudflare will give you a temporary `*.pages.dev` address.
7. Once the site looks right, add your custom domain in Cloudflare Pages.
8. Move the DNS/nameserver management for your existing Squarespace-registered domain to Cloudflare when ready.

Do NOT cancel your Squarespace domain registration. The domain can remain registered with Squarespace while Cloudflare handles DNS and hosting.

## Future additions

The site is intentionally structured to grow into:

- Blog/article system
- Destination pages
- Cruise reviews
- Camping/RV guides
- Affiliate product recommendations
- Travel videos / YouTube
- Downloadable guides and itineraries
- Newsletter
- Travel-planning / travel-agent services

The newsletter form is intentionally disabled for now so there is no paid service dependency.

## Important

When affiliate links are added, add a clear affiliate disclosure and the required disclosures for each affiliate program. When travel-agent services launch, add the appropriate business/legal information for the services and jurisdictions involved.
